# 🏨 Nestorria — Hotel & Property Booking Platform

Nestorria is a full-stack hotel and property booking platform built with the MERN stack. It allows users to explore properties, view property details, make bookings, and manage their reservations. Property owners can also list and manage their properties through a dedicated dashboard.

## 🚀 Features

### 👤 User Features
- User authentication with Clerk
- Browse available properties
- Search and explore properties
- View detailed property information
- Property image gallery
- Book properties for selected dates
- View and manage personal bookings
- Responsive user interface

### 🏢 Owner Features
- Owner dashboard
- Register as a property owner
- Add new properties
- Upload property images
- Manage listed properties
- View booking information
- Track property-related activity

### 💳 Booking & Payments
- Property booking management
- Booking price calculation
- Stripe payment integration
- Booking confirmation workflow
- Email notification support

### ☁️ Backend & Storage
- RESTful API architecture
- MongoDB database
- Cloudinary image storage
- Clerk authentication
- Express.js backend
- Node.js server
